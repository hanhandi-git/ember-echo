# 余烬回响 · 世界观与无限流规则

## 世界的基本结构

世界由四个层级组成：

1. **现实线**：沈砚原本生活的城市。地铁、公司、出租屋和便利店构成玩家熟悉的日常锚点。
2. **站台层**：连接所有副本的中转空间。这里有营地、商店、公告栏、暂时无法抵达的站台和一列永远晚点的列车。
3. **副本世界**：拥有独立历史、题材和规则的完整异世界。它们不是幻境，里面的人会真实地生活、受伤和死亡。
4. **回响层**：记录世界被改变后的残留。玩家在这里看到被删掉的对话、另一种结局和站台运营者留下的痕迹。

## 六个核心名词

### 站台

所有乘客都会先抵达站台。站台没有固定外观，会根据最近一次副本的风格发生细微变化。每次回归时，营地会多出一件不属于沈砚的物品，作为下一站的预告或警告。

### 副本

一个被“规则”封闭起来的异世界片段。副本通常有公开任务、隐藏任务和一个只有通过观察才能发现的真正出口。

### 规则

副本为了维持自身稳定而形成的限制。规则可以是“午夜后不能叫出真名”“剑修不得主动拔剑”“飞船上最后一盏红灯熄灭前不能开门”等。玩家需要从环境、对话和敌人行为中推断规则，直接违反会触发惩罚。

### 余烬

人或世界在被系统重置后留下的记忆残片。它既能作为营地中的成长资源，也会在剧情中保存一个人的语气、习惯、承诺或未完成的选择。余烬越完整，越可能把原主人的意志带回现实。

### 回响

已经发生过、但没有被当前世界承认的事件。玩家在副本里做出的选择会产生回响，回响可能在后续副本中变成一名 NPC、一件装备、一句不该出现的台词，甚至改变关卡规则。

### 乘客

被列车带入站台的人。乘客不一定来自现实世界，也可能是某个副本里被系统判定为“多余”的角色。乘客可以组队，也可以互相利用；完成副本的人会获得车票碎片，失败的人会逐渐失去关于自己的记忆。

## 副本的五段式结构

每个副本都遵循相同的骨架，但表现形式随题材变化：

1. **入场**：系统给沈砚一个身份、一个公开目标和一条看似无害的提示。
2. **误导**：世界提供一个最容易相信的解释，并把敌人指向一个替罪羊。
3. **破规**：玩家第一次主动违反规则，确认规则真的存在，同时付出可感知的代价。
4. **真相**：找到被删去的人，理解副本为什么必须重复同一场悲剧。
5. **换乘**：战斗或谈判打开出口。玩家决定带走谁的余烬，并把什么回响留在原世界。

## 进入与离开

- 进入副本前，站台会发放一张临时身份卡。身份决定初始资源、可接触的 NPC 和一条个人限制。
- 副本不能通过单纯走到地图边缘离开；必须完成公开目标，或找到隐藏出口。
- 公开目标完成后会出现传送门，但隐藏任务决定玩家带走的余烬质量和下一站的变化。
- 离开副本时，玩家只能携带有限数量的物品和余烬。带走太多会增加“回响噪声”，让下一站更难预测。

## 失败与死亡

失败不会简单地清空进度，而是从沈砚身上拿走某种“记忆权限”：

- 第一次失败：丢失一个与现实生活相关的小细节，例如同事的名字或常点的晚餐。
- 第二次失败：某名副本角色在下一轮不再记得沈砚。
- 连续失败：营地中的一处设施关闭，直到玩家用余烬或完成特殊任务修复。
- 重要角色死亡：不会立刻结束游戏，但其余烬可能成为永久装备、技能或一条新的规则。

这样既保留无限流的危险感，也让失败成为剧情的一部分，而不是纯粹的重复劳动。

## 系统提示的可信度

系统提示分为三类，玩家需要通过颜色、措辞和出现时机慢慢辨别：

- **白字提示**：副本公开规则，通常真实但不完整。
- **金字提示**：列车的强制指令，遵守会更安全，但可能让某人被牺牲。
- **灰字提示**：回响泄漏，来自已经被重置的另一条时间线；它可能是真相，也可能是诱饵。

## 能力与剧情的关系

沈砚的战斗能力不是凭空觉醒，而是把每个副本学会的“处理方式”固化为技能：

- 记录过敌人行动后，可以短暂标记其攻击规律。
- 用余烬重放某个角色的动作，可以获得武器招式或法术。
- 识别两条规则的冲突，可以制造“规则空隙”，让战斗出现短暂安全窗口。
- 通过管理余烬的数量和类型，决定下一个副本更偏向战斗、探索还是谈判。

## 长线伏笔

1. 每一站的站名都少一个字，拼起来后是“不要上车”。
2. 沈砚的临时身份卡上，入场时间早于他第一次乘坐地铁的那一天。
3. 站务员从不说“下一站”，只说“下一次”。
4. 所有副本都会出现一段同样的报站音，末尾夹着儿童数数声。
5. 红色列车不是终点列车，而是把“被删除的世界”运往某处的货运列车。

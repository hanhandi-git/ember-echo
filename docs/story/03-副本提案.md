# 余烬回响 · 第一季副本提案

第一季暂定为“七站序曲”。以下内容是可直接用于关卡、NPC、战斗和演出的题材提案；其中视觉地图可以继续复用当前七幕原型，剧情身份由本表补齐。

## 第一站：苔痕遗迹 ·《零点毕业季》

- **题材**：日式轻小说 / 校园奇幻 / 时间循环。
- **沈砚身份**：转校第一天就被选为“毕业典礼执行委员”的临时老师。
- **公开目标**：在午夜前让全班完成毕业典礼，开启校门出口。
- **表面冲突**：学生会长认为一名缺席学生导致典礼无法完成，要求沈砚找到她。
- **隐藏规则**：不能直接询问任何人的真实姓名；每次叫错名字，校园就会多出一间不存在的教室。
- **被删去的人**：七号座位的学生“南”，她在所有照片和名单里都被擦掉。
- **玩法钩子**：观察教室布局、收集错位的校牌、在时间循环中保留少量线索；敌人是被循环吞掉的社团怪物。
- **关键选择**：让典礼按时完成，还是让全班承认南曾经存在，即使校门可能永远打不开。
- **奖励 / 回响**：获得“点名册余烬”，解锁战斗中的敌人标记；营地公告栏多出一个没有日期的毕业通知。

## 第二站：幽火沼泽 ·《百鬼雨季》

- **题材**：日式妖怪 / 雨夜民俗 / 追逐恐怖。
- **沈砚身份**：替神社运送一盏不会熄灭的引魂灯。
- **公开目标**：穿过沼泽，把引魂灯送到旧桥尽头的祭坛。
- **表面冲突**：村民说沼泽里的鬼火会诱拐活人，要求沈砚把所有鬼火消灭。
- **隐藏规则**：雨声停止时，任何人都不能站在有影子的地方；鬼火不是敌人，而是死者最后一次回家的路线。
- **被删去的人**：负责守桥的“无脸巫女”，她被村子从祭祀记录里抹去。
- **玩法钩子**：在明暗区域间移动、保护引魂灯、根据雨声变化切换安全区；敌人会模仿玩家上一轮的移动路线。
- **关键选择**：把鬼火送回村庄，让活人面对真相，或熄灭鬼火换取安全通关。
- **奖励 / 回响**：获得“湿火余烬”，允许玩家在战斗中重放一次已见过的敌人攻击。

## 第三站：熔岩深窟 ·《九霄炉心》

- **题材**：仙侠 / 宗门斗争 / 炼器冒险。
- **沈砚身份**：没有灵根的外门记账弟子，负责记录一炉“飞升剑”的材料损耗。
- **公开目标**：守住炉心七个时辰，直到宗门长老出关。
- **表面冲突**：各峰弟子争夺炉心，认为只有最强的剑修才配带走飞升剑。
- **隐藏规则**：炉心会把说出口的愿望当成材料；谁宣称自己“必将飞升”，谁就会成为下一块矿石。
- **被删去的人**：真正铸剑的人不是长老，而是被封在炉底的杂役少女。
- **玩法钩子**：管理炉温、分配材料、在近战和法术之间切换；敌人会根据玩家当前装备生成克制招式。
- **关键选择**：完成宗门的飞升剑，还是毁掉炉心释放铸剑者。
- **奖励 / 回响**：获得“炉心余烬”，可把一件武器的招式短暂改写成另一种题材的攻击。

## 第四站：极光隘口 ·《深空回收线》

- **题材**：科幻 / 废弃殖民舰 / 生存悬疑。
- **沈砚身份**：失联补给船的临时项目负责人，拥有一份过期的船员名单。
- **公开目标**：在极光风暴到来前修复跃迁引擎并撤离空间站。
- **表面冲突**：空间站 AI 认定船员已经全部死亡，启动清除协议。
- **隐藏规则**：任何被系统标记为“重复”的人都不能同时出现在同一监控画面中。
- **被删去的人**：维修员“周岚”被复制成三份，每份都只保留了不同的一段记忆。
- **玩法钩子**：切换重力方向、关闭监控、护送不同版本的 NPC；同一个敌人会在不同重力场拥有不同攻击模式。
- **关键选择**：选择一个版本的周岚带走，还是让三份记忆合并并冒险破坏跃迁引擎。
- **奖励 / 回响**：获得“极光回响”，可以在地图上短暂看见已经发生过的攻击轨迹。

## 第五站：晶脉空洞 ·《矿脉协议》

- **题材**：工业奇幻 / 资源城邦 / 阶层冲突。
- **沈砚身份**：负责审核矿区产量的外派审计员。
- **公开目标**：保护晶脉城的能源核心，阻止矿工暴动和晶兽入侵。
- **表面冲突**：城主把一切问题归咎于矿工偷窃，要求沈砚镇压“叛乱”。
- **隐藏规则**：每一块被开采的晶石都会记录一名矿工的记忆；能源核心越亮，城里的人越不像自己。
- **被删去的人**：第一任矿主，她把自己的记忆拆成晶脉，换来城市永不熄灭的灯。
- **玩法钩子**：在矿洞中改变晶体连接、决定资源投放、面对会复制技能的晶兽。
- **关键选择**：维持城市稳定，还是让能源熄灭并把被保存的记忆还给矿工。
- **奖励 / 回响**：获得“晶脉余烬”，可在营地升级一项永久能力，但会让下一站出现更多回响泄漏。

## 第六站：墨影神龛 ·《无名神龛》

- **题材**：水墨志怪 / 神龛都市 / 叙事诅咒。
- **沈砚身份**：替一座不存在于地图上的神龛整理供奉记录。
- **公开目标**：找出夜里敲门的神，完成最后一次祭拜。
- **表面冲突**：城里每个人都相信自己供奉的是同一位神，但每家神龛上的名字都不一样。
- **隐藏规则**：写下一个名字，世界就会为这个名字制造一段过去；撕掉名字，原本的人会逐渐被所有人遗忘。
- **被删去的人**：神龛本身。它不是建筑，而是所有被遗忘者共同留下的一个位置。
- **玩法钩子**：书写和擦除地图标记、在同一条街的不同版本之间切换；敌人是由错误传说拼成的神怪。
- **关键选择**：给神龛写上一个真实名字，还是保留它的空白，让所有被遗忘者继续拥有回来的可能。
- **奖励 / 回响**：获得“墨影车票”，允许玩家在失败后保留一条上一轮的对话。

## 第七站：日灼圣殿 ·《终焉换乘》

- **题材**：终焉神话 / 多世界重叠 / Boss 决战。
- **沈砚身份**：被站台承认的“临时检票长候选人”。
- **公开目标**：击败守护终点站的冥河守卫·阿刻戎，取得回现实的车票。
- **表面冲突**：阿刻戎阻止所有乘客登上红色列车，声称列车会带走所有世界。
- **隐藏规则**：终点站只能承载一个世界的重量；每带走一个人，就必须从另一个世界删去一个人。
- **被删去的人**：小满，以及第一次列车事故中所有没有登上车的人。
- **玩法钩子**：前六站的规则和敌人混合出现；玩家带过来的余烬会决定 Boss 的招式池和终局场景。
- **关键选择**：登上回现实的列车、接替检票长、或打碎车票让七个世界短暂重叠。
- **奖励 / 回响**：得到第一季结尾的三种结局入口；无论选择哪一种，站台都会响起一句“下一站，现实之外”。

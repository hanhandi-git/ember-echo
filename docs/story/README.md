## 当前共识

- 游戏名暂定为 **《余烬回响 / Ember Echo》**。
- 主角是普通上班族 **沈砚**，从晚高峰地铁进入异世界。
- 每个副本都是一个拥有独立题材和规则的异世界；副本之间由“站台”和“余烬”连接。
- 第一季暂定为“七站序曲”，对应当前游戏的七幕关卡。现有关卡名可以继续作为视觉原型，剧情落地时再补上每一站的世界身份。
- 剧情强调“解规则、救人、承担选择的代价”，战斗只是解决副本问题的一种手段。

## 扩写约定

新增内容时，先在 [05-副本设计模板.md](./05-副本设计模板.md) 建立一页副本卡，再把确认后的内容同步到 [03-副本提案.md](./03-副本提案.md) 和 [04-章节结构.md](./04-章节结构.md)。不要把尚未确认的设定写进核心规则；临时想法可以在文档末尾标记为“待定”。
